# QG-DPanel-Appstore

一个DPanel的第三方应用商店（理论上支持1Panel）


本仓库收录：
 - 官方应用商店以及部分第三方仓库均未收录的应用
 - 移植来自[CasaOS-AppStore-Play](ttps://github.com/Cp0204/CasaOS-AppStore-Play)的数据

以下应用商店已收录的不会收录：
 - [1Panel官方应用商店](https://github.com/1Panel-dev/appstore)
 - [第三方应用商店（qyg2297248353/appstore-dpanel）](https://gitee.com/qyg2297248353/appstore-dpanel)
 - aaPanel官方应用商店

（大部分收录软件适用于NAS）

面板中添加自定义应用商店：
